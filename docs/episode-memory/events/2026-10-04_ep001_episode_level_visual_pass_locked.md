# EP001 Episode-Level Visual Pass — LOCKED

Status: LOCKED

The episode-level visual direction for EP001 is fully approved and locked. Canonical principles include:

- The 20-minute episode must feel like one continuous visual film, not 16 disconnected scenes.
- Macro acts:
  1. 00:00–02:38 Human Action / Hidden System
  2. 02:38–06:25 Request Journey / Discovery
  3. 06:25–09:20 Decision Core
  4. 09:20–12:50 System Under Stress / Failure Branch
  5. 12:50–17:00 Trust Creation / Return to Success
  6. 17:00–20:00 Memory / Recap / Bridge Forward
- Camera grammar:
  - Close = human consequence or critical local mechanism.
  - Medium = main node plus local mini-world.
  - Wide = causal relation among multiple nodes.
  - Full Map Wide = rare reveal/payoff, not default view.
  - Forward movement = journey.
  - Push-in = decision/understanding.
  - Pull-back = context/reveal.
  - Horizontal travel = request movement.
  - Vertical departure = branch/change of outcome.
  - Return toward Phone = architecture becoming human consequence.
- Phone recurring human anchor: Login → Submitting → Waiting → Try Again → Dashboard → Reopen → Next Action.
- Secondary cards act as temporary local mini-worlds around the current main object, never as a checklist.
- Failure has different geography from success: main success path stays horizontal; failure branch separates downward.
- Full architecture map is revealed progressively and becomes a payoff only after the viewer has travelled through it.
- Critical rule: never activate an object before the story gives the viewer a reason to look at it.
- Previous SHOT 01 visual draft is provisional and must be rebuilt under this locked episode-level direction.
