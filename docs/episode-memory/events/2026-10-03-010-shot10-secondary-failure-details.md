# EP001 Creator Correction — SHOT 10 Secondary Failure Details

Date: 2026-10-03
Status: CREATOR CORRECTION / ACTIVE

For SHOT 10, all visible secondary items inside the Expired Session, Invalid Token, and Account Status cards must be explained in narration, not merely named.

Required detail:
- Expired Session: Refresh expired token, Session timed out, Fresh Auth Required.
- Invalid Token: Invalid Signature, Malformed Token, Token Not Recognized.
- Account Status: Account Locked, Disabled Account, Contact Support.

Narration rule remains: explain meaning in simple language, name exact diagram term, explain what information/state it represents, and why it changes the journey. Do not turn the explanation into a glossary or protocol tutorial.
