# EP001 Creator Workflow Correction — Script Approval First

Date: 2026-10-02
Status: ACTIVE

The creator changed the collaboration workflow for future script development.

## New workflow

Before presenting detailed production instructions for a new section, first present only the proposed script in a compact approval format containing:
- exact planned timeline;
- shot title;
- narration text split into exact planned spoken time ranges.

The creator first reviews and approves/corrects the narration itself.

Only after narration approval should the assistant expand that approved section into the full production contract used previously, including:
- voice direction;
- ElevenLabs generation unit;
- pauses;
- semantic sync anchors;
- visual intent;
- object/state changes;
- secondary object behavior;
- camera intent;
- retention role;
- Reel boundaries where applicable;
- success/failure criteria.

After the detailed production contract is approved, LOCK the section and record the lock in episode memory.

This workflow prevents unnecessary visual/production detail from being developed around narration that may still change.
