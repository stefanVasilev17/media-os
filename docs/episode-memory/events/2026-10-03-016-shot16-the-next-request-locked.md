## Canonical narration

**19:15–19:27**  
“A few seconds later, you click something inside the Dashboard and another request leaves the app. But this time, something important is missing: **your password is not being sent again.**”

**19:27–19:40**  
“Instead, the request can carry the authentication proof created during Login — perhaps through a Session ID, a Cookie, or a JSON Web Token — so the system can connect this new action to the identity it already trusted.”

**19:40–19:51**  
“That sounds convenient, but it creates a new architectural problem. Every new request now depends on the system recognizing that proof, checking whether it is still valid, and rebuilding enough identity context to know who is acting.”

**19:51–20:00**  
“So the next question is no longer how you log in. It is this: **once the password is gone, how does the system remember who you are?**”
