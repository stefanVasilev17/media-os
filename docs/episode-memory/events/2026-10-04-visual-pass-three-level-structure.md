# EP001 Visual Pass — Three-Level Structure

Status: LOCKED PROCESS CORRECTION

The visual pass is organized in three levels and must be executed in this order:

1. Episode-level visual pass
   - Decide how the full ~20-minute film breathes as one continuous visual experience.
   - Define when the camera is close, medium, or wide.
   - Define when the Living Architecture Map grows or contracts.
   - Define when the story returns to the Phone.
   - Define mini-world reveals.
   - Define when and how the failure branch separates from the main path.
   - Goal: avoid 16 individually good shots that feel like 16 different videos.

2. Shot-level visual pass
   - Only after the episode-level rhythm is locked, go through SHOT 01 → SHOT 16 and lock exact choreography for each shot.
   - Shot choreography must inherit the episode-level camera rhythm, reveal strategy, visual hierarchy, and story arc.

3. Component consistency pass
   - Review repeated visual concepts across the episode: Request, Lookup, Decision, Waiting, Failure, Response, Proof, Restore.
   - Convert them into one consistent visual grammar so repeated concepts are represented consistently instead of inventing a new visual mechanism in every shot.

Precedence rule: Episode-level visual logic constrains shot-level choreography; component consistency pass normalizes recurring concepts after shot choreography is known.

The previously drafted SHOT 01 visual choreography is provisional until the Episode-level visual pass is locked.
